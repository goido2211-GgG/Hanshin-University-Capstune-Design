# VoiceAI 시험 계획

기준일: 2026-11-09 (Asia/Seoul).

## 1. 현재 실행 결과와 시험 전제

**아래 모든 사례의 실제 Unity 결과는 미실행이다.** 예상 결과는 목표 계약이며 현재 기능이 통과했다는 뜻이 아니다. 문서 검사는 Unity 시험을 대신하지 않는다.

현재 코드에 있는 채팅·음성·상자 이동/집기부터 기준을 기록한다. Runner·로컬 중지·규칙 기반 오해·반자율 탐색·퍼즐 시험은 해당 구현 이후 수행한다. 지금은 시험용 씬·코드·설정도 만들거나 변경하지 않았다.

- 환경 기록: Unity 버전, 플랫폼, timeScale, 사용 씬, 시험 대상 코드 버전, 가짜/실제 API 구분.
- 기존 시험 씬 후보: `Assets/Scenes/ssm.unity`. 현재 red_box 중심이며 버튼·서랍·열쇠·문은 없다.
- 가짜 API는 `AgentBrain`의 주입 가능한 전송 함수와 향후 테스트 경계를 이용한다. 응답 지연·역순·취소 무시를 의도적으로 재현한다.
- 실제 음성 시험은 장치·권한·전사 결과를 기록한다. 키·인증 헤더·비밀 파일 내용은 로그에 넣지 않는다.
- 기록할 관측값: 세션/명령 ID, 출처, 상태 전이, 의도 시각, 행동 시작/종료 시각, 위치·인벤토리·퍼즐 상태, 이벤트 횟수.
- 1초 대기는 timeScale=1에서 1초 이전 실행 없음과 첫 가능한 프레임의 실행을 확인한다. “약 3초” 허용 오차는 미확정이므로 실제 경과를 기록하고 최종 합의 후 판정한다.
- 즉시 중지는 입력을 처리한 프레임 이후 추가 이동·조작 없음, 네트워크 응답 대기 없음이 기준이다.
