# 첫 번째 맵 버튼 연결

## 버튼 프리팹 규약

1. 씬의 월드 버튼 루트에 `AIButton` 태그를 지정한다. 같은 루트에 `AgentButton`과 `AgentInteractable`을 둔다. 기존 플레이어용 `Interactable`과 Collider는 기존 설정을 사용한다.
2. `AgentInteractable`의 `Id`는 같은 씬의 모든 상호작용 대상 사이에서 고유해야 한다. 예시는 `red_button`이다. `Display Name`에는 `빨간 버튼` 같은 이름을 입력한다. `AgentButton > Aliases`에는 `1번`, `문 옆에 있는`처럼 팀에서 정한 구분 값을 넣는다. 문 옆이라는 표현은 별칭으로 등록해야 한다.
3. `Approach Point`에는 버튼 앞에서 로봇 루트가 설 위치를 지정한다. 로봇 루트와 같은 높이이며 직선으로 접근 가능한 위치를 사용한다. `Interaction Distance`는 접근 지점에서 허용하는 3D 위치 오차다. 기존 로봇 이동은 평면 직선 이동이므로 장애물을 우회하지 않는다.
4. `On Press`에 팀원 퍼즐의 인자 없는 공개 메서드를 연결한다. 기존 F 동작과 같은 퍼즐 메서드를 각각 연결할 수 있다. 이벤트는 호출 완료를 보고한다. 잠금이나 쿨다운에 따른 성공 여부까지 전달하려면 `IAgentButtonReceiver.TryPress()`를 구현하고 `Receiver`에 컴포넌트를 지정한다. 수신기를 지정하면 그 경로만 실행한다. 수신기의 `false`는 조작 실패로 처리된다.
5. `Min Trust`는 기존 규칙으로 검사된다. 키 없는 시험에서는 기본 신뢰도가 적용된다. `Allow Autonomous Exploration`은 버튼 명령에 필요하지 않다.

활성 버튼은 명령을 받을 때 같은 씬의 태그로 검색하므로 런타임에 생성된 프리팹도 대상이 된다. 이름, ID, 표시 이름, 별칭을 비교한다. `저 버튼`과 `버튼`은 후보 하나가 있을 때만 선택하며 조준이나 시선 추적을 하지 않는다. 같은 이름이 여러 개거나 ID가 중복되면 명령을 거부한다.

## 키 없이 확인

`VoiceAI_Integration_Test.unity`를 복제해 로컬 시험 씬으로 쓰고 `VoiceAgent > Initialize Api On Awake`를 끈다. 키 없이 채팅으로 `1번 버튼 앞까지 가`, `빨간 버튼 눌러`, `멈춰`를 실행한다. 임시 큐브에 어댑터를 연결하고 인자 없는 시험 메서드나 시험용 수신기에서 별도 표시 오브젝트의 상태를 바꾸도록 연결하면 실행 여부를 확인할 수 있다. `앞까지 가`는 이동만 한다. 이동 도중 Esc를 눌러 이벤트가 호출되지 않는지 확인한다. 음성 시험은 기존 음성 전사 연결이 필요하다.

시작 직후 탐색은 비활성이다. 향후 칩 장착 코드에서 `VoiceAgent.SetExplorationEnabled(true)`를 호출하면 탐색 컴포넌트와 탐색이 허용된 대상이 있는 경우 기존 이동·조사가 가능하다. 중지 후에는 탐색 권한이 있는 상태에서 `탐색 재개`를 입력한다. 권한을 철회하려면 `SetExplorationEnabled(false)`를 호출한다.

최신 main의 `ssm.unity`는 `stage_01` VoiceAI 테스트 구성이며, 새 월드 버튼이나 퍼즐 이벤트 연결을 확인할 수 없었다. 원본 씬과 프리팹의 연결 작업은 팀 버튼이 준비되면 위 규약으로 진행한다.
